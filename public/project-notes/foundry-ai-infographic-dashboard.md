# Foundry AI Infographic Dashboard

An evidence-based case study of enterprise KPI exploration and generated infographic workflows.

## Overview

Explore OTT streaming KPIs and turn business questions into infographic summaries. The supplied images show KPI charts, a prompt interface and saved generated-infographic history.

Origin: 2026 independent Foundry work. Four supplied screenshots were reviewed alongside CV descriptions. Only two privacy-reviewed screenshots are included; this repository is a case study without an exported Foundry application.

## Technical Approach

The CV describes Foundry transformations, Ontology, AIP Logic natural-language interactions and Gemini infographic generation. Screenshots corroborate the visible dashboard/prompt/history experience; they do not independently verify model configuration, backend calls or complete pipeline implementation.

## Tech Stack

Palantir Foundry; Ontology. AIP Logic and Gemini integration are CV-supported claims, with no local source export or execution trace.

## Key Features

- Streaming KPI dashboard
- natural-language prompt interface
- generated infographic display
- previous-generation history.

## Architecture / Pipeline

Enterprise data --> Foundry transformations --> Ontology --> prompt workflow --> generated infographic history
